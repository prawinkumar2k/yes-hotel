# YES HOTELS — System Audit, 15 Oct 2026

For the hotel owner and the next developer: what was checked, what was broken, what was fixed, how it was verified, and what is still open. Everything below was measured or tested; nothing is assumed from a successful build.

## How it was checked

- **Every page, every role.** A browser robot signed in as Admin, Manager, Reception, Housekeeping and a guest. It opened each page, recorded every API call the page made, and flagged:
  - error screens and "Access Denied"
  - failed API calls (4xx/5xx)
  - content wider than the screen
- **Every sidebar link, per role.** Checked on the local production build and on the live server. Admin has 23 links, Manager 22, Reception 15 and Housekeeping 1; none had a problem.
- **Screen widths:** 375, 390, 768, 1024, 1280 and 1536 px.
- **Automated tests:** 330 tests in 50 files, unit plus HTTP integration against a real MongoDB replica set. One run had a test file fail during setup while the machine was busy building; the immediate re-run passed all 330.
- **Two-browser live-chat test**, on the production build and on the live server. The guest and Reception saw each other's messages live both ways, and the history was still there after a reload. Passed.

## Defects found and fixed (this round)

| # | Defect | Fix |
|---|---|---|
| 1 | **Admin got "Access Denied"** on Gallery, FAQs, Content, Reviews, Testimonials, Complaints, Contact messages, Pricing rules and Multi-property, so nobody could edit the website | Admin's permission list now includes pages no other role is granted; no other role changed |
| 2 | Reception's **check-in and room-move room lists were empty** (403 on `/api/rooms`) | Uses the registration availability API Reception already has, for the stay's dates, clean rooms only |
| 3 | The phone bottom menu offered Dashboard, Front Desk, Rooms and Cleaning to **every role**, even ones that can't open them | Shows only the screens the role can open |
| 4 | The Housekeeping sidebar led to manager screens whose data is blocked for them | Housekeeping sees only "My Rooms to Clean" (their own screen) |
| 5 | The general API limit of 300 calls per 15 min per connection could lock the desk out, because all staff share the hotel Wi-Fi | Raised to 3,000 per 15 min; the login limit (failed attempts only) is unchanged |
| 6 | Cleaning photos were stored at full camera size (3–5 MB), three times, including in the audit log | Resized on the phone (about 200 KB) and validated on the server; the audit log records only that a photo was attached |
| 7 | Content wider than the screen at 375 px: Verification Queue filters, Audit Log filters, Settings tabs, Maintenance cards, In-House signature block | These now wrap, stack, or scroll inside their own area |
| 8 | In production, the `/gallery` page redirected to `/gallery/` (a photo folder has the same name) | The static file server no longer redirects folders |
| 9 | The revenue chart tooltip showed **$** | Shows ₹ |

**Also new in this round:**
- **Logo:** the YES HOTELS logo on the website, sign-in pages, staff app, favicon and app icons, invoices, receipts and the guest registration card.
- **Email sign-in:** guests can sign in with a 6-digit code sent to their email.
- **Live chat:** website chat with Reception and Admin over Socket.IO. Messages are saved before they are sent, and screens re-sync after a reconnect.

## Remaining items and blockers

| Item | Why it is open |
|---|---|
| **Email sign-in codes in production** | No mail account is set on the server (`EMAIL_USER` / `EMAIL_PASS`). Until then the live site tells real guests "Email sign-in isn't available". Needs a Gmail address and app password. |
| **Room types: Executive and Deluxe only** | Live has Standard (101–106, used by 3 bookings), Deluxe (201–206), Executive (301–304) and Signature Suite (401–403). Nothing is moved until the owner confirms which room numbers are which type, and the rates. |
| **Terms, Privacy and Cancellation pages** | No text exists, so the pages say "being updated". The policies must come from the hotel (Admin → Content). |
| Request size limit | **Done (later):** photos are resized on the device and the limit is now 10 MB. |
| SEO landing pages and booking attribution | **Done (later):** completed, tested and deployed. |
| Shortening a stay, moving rooms | These do not yet adjust the bill automatically. |
| Room Rack tape chart and Monthly MIS grid on phones | They scroll sideways inside their own area by design (a date grid and a spreadsheet). |
